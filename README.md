# 长龙航网助手 · macOS 版

> 把长龙航空「畅飞卡 / 积分兑换」的放票日历和余票，做成一个本地网页大盘。
> 浏览器打开就能用，数据全部留在你自己的 Mac 上，不上传任何云端。

当前版本：**v2.2.0** · 仓库：<https://github.com/beelzebubxbh/clairline>

这是 [eureka-wu/clairline](https://github.com/eureka-wu/clairline) 的 **macOS 移植分支**。
原版只支持 Windows（改注册表设代理 + `certutil` 装根证书 + WebView2 桌面壳），
本分支去掉了这些系统级依赖，改成**在本机起一个网页服务，用浏览器访问**。

## 它能干什么

| 功能 | 说明 |
|---|---|
| **航网大盘** | 490 条直飞航线拓扑，一张卡片一条线，显示班次、首末班时刻、可兑换天数 |
| **放票日历** | 按日期显示能不能兑，点日期胶囊就地弹出各班次余票（张数 / 机型 / 经停） |
| **地图探索** | 全屏 SVG 航网图，绿线为近期可兑，可缩放漫游 |
| **本地缓存** | 查过的结果写进 SQLite，再点同一个日期 0 毫秒出结果，不再打接口 |
| **往返搜索** | 选「周六去 · 周日回」这类节奏，一次筛出往返两程都有票的目的地 |
| **重点监控** | 把常飞航线钉住，手动触发巡检（默认不自动跑） |
| **会员信息** | 自动读取你的会员等级与畅飞卡，显示在右上角 |

## 快速开始

### 第 1 步：装 Node（仅用于构建前端）

```bash
brew install node
```

> Python 不用装，用 macOS 自带的 `python3` 即可（3.9+）。
> 脚本体只依赖标准库，**没有 pip 依赖**。

### 第 2 步：拉代码并启动

```bash
git clone https://github.com/beelzebubxbh/clairline.git
cd clairline
./run.sh
```

浏览器打开 <http://127.0.0.1:3000>。首次启动会自动构建前端（约 1 分钟），之后秒开。

### 第 3 步：手机号登录

点右上角「**同步长龙登录**」：

1. 输入你在长龙航空注册的 **11 位手机号**
2. 点「获取验证码」，拖动完成网易易盾的**滑块验证**
3. 输入手机收到的 **6 位短信验证码**，点「立即登录」

完成后右上角会显示你的会员姓名与等级，可以开始查票了。

> **不需要装 mitmproxy、不需要装根证书、不需要开系统代理**——
> 登录态由长龙官方接口直接签发，全程在浏览器里完成。

## 关于「登录态」

### 怎么来的

走的是长龙官方的小程序登录接口：

```
手机号 + 易盾 validate  →  getVerifyCode  →  短信验证码
                        →  mobileCodeLogin  →  loongairToken + refreshToken
```

`loongairToken` 就是一个 base64 的 UUID（`Cookie: SESSION=` 同值），不是 JWT、不带过期时间。
拿到之后所有查询都靠它。

### 会过期吗

会。实测两个样本：抓包的 Token 活了约 **18 小时**（10-26 15:21 → 10-27 09:39 失效），
短信登录的 Token 只活了约 **3.5 小时**（10-27 09:44 → 13:10 失效）。
所以寿命不固定，可能几小时到十几个小时。

失效时：

- 程序会**先尝试用 `refreshToken` 自动续期**；
- 但官方并没有公开续期接口——社区流传的两个方法名实测在网关里都返回 `Not Found`，
  所以续期大概率不生效，属于「尽力而为」；
- 续期失败就会提示你重新登录，点右上角会员胶囊，手机验证码登录一次即可（约 10 秒）。

> 顺带说明一个上游的坑：上游项目虽然写了 `refreshToken` 续期，但保留了「凭据跨自然日就清空」
> 的旧逻辑，而清空发生在续期判断之前——所以续期永远走不到。本分支删掉了强制清空，
> 至少让「Token 还没真过期」的情况下能继续用。

### 存在哪

```
~/.clairline/credentials.json   Token、会员档案（600 权限）
~/.clairline/data/changlong.db  航班、日历、余票缓存
```

### 备用方案（正常情况下用不到）

如果哪天短信通道抽风（易盾滑块加载不出来、官方接口改版），还可以退回**抓包**方式取 Token：

```bash
./refresh-token.sh
```

它会临时起 mitmproxy、装根证书、抓一次微信小程序的请求头。需要 `brew install mitmproxy`
和一次 `sudo` 装证书，抓完记得按 FAQ 卸载证书。

## 往返搜索怎么用

这是跟「查单条航线」互补的一个功能——回答的是**周末去哪**，而不是**这条线有没有票**。

点右上角 **往返搜索**，然后：

1. 选**出发地**（必填）
2. 选**目的地**——**留空就是「不限」**，会枚举这个城市所有直飞目的地
3. 选**行程节奏**：周六去周日回 / 周五去周日回 / 周五去周一回，或自定义区间 + 停留天数
4. 选**查未来几个周末**（2 / 4 / 6 / 8）
5. 可选：限定**出发时段**和**回程时段**（比如只想要晚上走的）
6. 点「搜索有票往返」

结果会列出**去程和回程同时有票**的目的地，勾选「同时查询具体航班」还会带上航班号、
起降时刻、剩余张数和往返总价。

两个实现上的取舍，说明一下：

- **日历级判断走本地缓存**。往返判定就是拿 `flight_calendar` 做一次双向 JOIN
  （去程 A→B 有票 且 回程 B→A 有票），所以「只给出发地、枚举全部目的地」也是毫秒级，不打外网。
- **具体航班要现查**。日历只知道「那天有票」，不知道几点飞、剩几张。
  这部分走 `secCardSearchFlights`，受 **3～30 天**窗口限制；超出窗口的日期会明确标注
  「只能确认日历有票、看不到具体航班」，不会假装查过。

## 日常使用

```bash
cd clairline
./run.sh                  # 启动服务
./refresh-token.sh        # 登录态失效时才需要跑
```

想让服务一直在后台跑：

```bash
nohup ./run.sh > /tmp/clairline.log 2>&1 &
```

停止：

```bash
pkill -f "backend/server.py"
```

## 常见问题

<details>
<summary><b>页面打不开 / 端口被占用</b></summary>

默认端口是 3000。检查一下：

```bash
lsof -nP -iTCP:3000 -sTCP:LISTEN
```

要换端口，改 `backend/server.py` 第 47 行的 `PORT = 3000`。
</details>

<details>
<summary><b>提示「登录态已失效」或者一直 403</b></summary>

正常情况下会先自动用 `refreshToken` 续期，你什么都不用做。

如果续期也失败（比如很久没打开过），点右上角会员胶囊重新用手机验证码登录一次即可。

顺带一个容易踩的坑：接口对 `Accept-Encoding` 请求头有硬性校验，
缺了会直接返回 403（不是 TLS 指纹问题，网上常见的判断是错的）。代码里已经强制补齐。
</details>

<details>
<summary><b>收不到短信验证码 / 滑块加载不出来</b></summary>

按顺序排查：

1. **滑块加载不出来**：网易易盾 SDK 是从 `cstaticdun.126.net` 加载的，
   需要外网可达。检查浏览器控制台有没有报错。
2. **提示「验签失败 (103900)」**：滑块没真正通过就点了发送，重新拖一次。
3. **提示「验证码不正确 (200221)」**：验证码过期（一般 5 分钟），重新获取。
4. **收不到短信**：确认手机号是长龙航空注册的那个号码；运营商拦截也可能导致收不到。
</details>

<details>
<summary><b>抓完想把根证书删掉</b></summary>

```bash
sudo security delete-certificate -c "mitmproxy" /Library/Keychains/System.keychain
```

删了不影响使用，只是下次刷新登录态时要重新装一次。
</details>

<details>
<summary><b>数据存在哪？怎么全部清空？</b></summary>

```
~/.clairline/credentials.json   登录态（600 权限）
~/.clairline/data/changlong.db  航班、日历、余票缓存
```

全部清空：

```bash
rm -rf ~/.clairline
```
</details>

<details>
<summary><b>Windows 上能用吗？</b></summary>

用上游原版：[eureka-wu/clairline](https://github.com/eureka-wu/clairline)，
它提供打包好的单文件 exe。本分支的改动是往 macOS 方向去的，不适合 Windows。
</details>

## 和原版的差异

如果只是想用，上面就够了。下面是给想看代码的人准备的。

| 改动 | 原因 |
|---|---|
| 删除 `capture_manager.py` / `proxy_util.py` / `capture_addon.py` | 依赖 `winreg` 改注册表代理、`certutil` 装证书，macOS 上无法运行 |
| 删除 `app_desktop.py` / `build_exe.py` | WebView2 桌面壳与 PyInstaller 打包，浏览器版不需要 |
| 新增 `backend/mac_auth.py` | 提供与原 `capture_mgr` 完全相同的接口，`server.py` 只改一行 import |
| 新增**手机短信直登** | 接官方 `getVerifyCode` / `mobileCodeLogin` 接口 + 网易易盾滑块，替代抓包 |
| 保留 `refresh_token.py` / `refresh-token.sh` | 仅作短信通道不可用时的兜底 |
| 修正 403 原因 | 原代码注释认为是 WAF 校验，实测确认**缺 `Accept-Encoding` 才会 403** |
| 取消「跨自然日强制作废凭据」 | 原逻辑隔天就把还能用的 Token 清空，改为用到报错再刷新 |
| 关闭「打开页面自动全网普查」 | 原逻辑会在页面加载时自动跑 397 条航线 |
| 全网普查限速 | 原版 4 线程 + 0.25 秒微延迟 ≈ 8 次/秒；改为全局 1.1 秒/条（397 条约 7 分钟） |
| 数据目录迁到 `~/.clairline/` | 仓库保持干净，`git status` 不会有脏文件 |

### 接口能力边界（实测）

| 接口 | 用途 | 限制 |
|---|---|---|
| `getSecCardRedeemedCalendar` | 放票日历 | 实际返回 **396 天**（界面目前只展示前 61 天） |
| `secCardSearchFlights` | 查具体班次余票 | **仅限提前 3～30 天**，超出报 `ErrorCode: 1` |
| `sales_user_userDetailInfo` | 会员档案 | — |

日历状态值语义：

| 值 | 含义 |
|---|---|
| `1` | 有 1 个可兑航班 |
| `0` | 可预约但无票 |
| `-1` / `-2` | 不可兑 / 未放票 |
| `-3` | 超出预约窗口 |

## 数据与隐私

- **不联网到任何第三方**：除了长龙官方接口，没有遥测、没有统计、没有云端。
- **凭据不出本机**：Token 只在 `~/.clairline/` 和本地 SQLite 里。
- **根证书按需安装**：抓 Token 时才需要，抓完可以删（见上面 FAQ）。
- **代码可审计**：全部逻辑都在这个仓库里，没有二进制。

## 更新日志

### v2.2.0 — 手机短信直登（2026-10-27）

- 新增**手机号 + 短信验证码登录**，接长龙官方 `getVerifyCode` / `mobileCodeLogin` 接口，
  配合网易易盾滑块验证。**不再需要 mitmproxy、根证书和系统代理。**
- 遇到 403 / `100001` 时会先尝试 `refreshToken` 续期再重试（官方未公开续期接口，实测大概率不生效，属于尽力而为）。
- 修正上游遗留问题：续期逻辑与「凭据跨自然日清空」矛盾——清空发生在续期判断之前，
  导致续期永远用不上。本版删除了强制清空。
- 登录成功后不再自动触发全网普查（原会瞬间打 397 次接口）。
- `db.py` 新增 `refresh_token` 列（自动迁移，无需手动操作）。
- `loongair_client.py` 去掉 `requests` 依赖，改回标准库，保持零第三方依赖。

### v2.1.0 — 往返组合搜索（2026-10-26）

- 新增**往返搜索**：选「周六去 · 周日回」这类节奏，一次筛出两程都有票的目的地。
  支持定向查询（指定目的地）和广撒网（目的地留空，枚举全部直飞城市）。
- 支持自定义区间 + 停留天数，以及出发/回程时段过滤。
- 可选拉取具体航班号、起降时刻、剩余张数与往返总价。
- 版本号升至 v2.1.0；「检查更新」改为比对本仓库的 Release。

### v2.0.0-macos — macOS 移植（2026-10-26）

- 移除 Windows 专属实现：注册表系统代理、`certutil` 装根证书、WebView2 桌面壳、PyInstaller 打包。
- 改为在本机起网页服务，浏览器访问 `http://127.0.0.1:3000`。
- 登录态获取从「常驻抓包」改为「按需抓一次」（`refresh-token.sh`）。
- 修正 403 的真实原因（缺 `Accept-Encoding`，不是 TLS 指纹）。
- 取消「跨自然日强制作废凭据」，改为用到报错再刷新。
- 关闭「打开页面自动全网普查」，并把全网普查限速到 1.1 秒/条。
- 数据与凭据迁移到 `~/.clairline/`。

## 已知限制

- 班次查询有 3～30 天的窗口限制，日历虽然给 396 天，但超出 30 天查不到具体班次。
- 依赖长龙的私有接口，对方随时可能改动，届时需要重新适配。
- 只支持 macOS（本分支）和 Windows（上游）。
